=================================================================
OSSA-2026-003: Remote code execution through Vitrage query parser
=================================================================

:Date: March 03, 2026
:CVE: CVE-2026-28370

Affects
~~~~~~~
- Vitrage: <12.0.1, ==13.0.0, ==14.0.0, ==15.0.0

Description
~~~~~~~~~~~
Khalil Lemtaffah (Nokia) reported a vulnerability in the Vitrage 
query parser. A user allowed to access the Vitrage API may trigger 
code execution on the Vitrage service host as the user the Vitrage 
service runs under. This may result in unauthorized access to the 
host and further compromise of the Vitrage service. All deployments 
exposing the Vitrage API are affected.

~~~~~~~
